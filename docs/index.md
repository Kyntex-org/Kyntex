# Kyntex documentation

Kyntex is a wearable-sensing prototype for motion, fit, and training-session
telemetry. These documents distinguish the system that exists today from future
research directions.

## Documentation map

- [Problem and design goals](problem.md)
- [Current solution](solution.md)
- [Technical architecture](technology.md)
- [Development roadmap](roadmap.md)
- [Hardware-free software demo](demo.md)

The current system does not measure tendon stiffness and is not a medical
device. Any tendon-response work described in the roadmap is exploratory.
